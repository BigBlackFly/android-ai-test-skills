## 使用时机与入口

当入口存在但滚动／定位区域不明确，或分屏、旋转后布局改变时加载；它不是一个可点击的独立设置页面。

入口：设置各页面。到达后按下面的可见控件识别，不仅凭页面背景判断。

## 页面识别与布局

双栏界面左侧负责模块导航，右侧负责当前内容；单栏界面进入模块会切换整页。大屏横竖屏通常双栏，小屏／小窗为单栏，分屏比例可改变布局。

## 关键控件：形状、位置与操作目标

位置均相对**当前页面的内容区或弹窗**，不是固定屏幕坐标。颜色只是辅助线索；优先结合标签、控件形状及相邻元素识别。

| 控件／入口 | 外观特征 | 相对位置 | 操作目标／状态区别 | 局部图 |
|---|---|---|---|---|
| 导航区 | 窄列，模块图标和名称 | 双栏左侧 | 滚动此区寻找一级模块 | [图 1](./images/focus_01.png) |
| 内容区 | 较宽列，标题和设置控件 | 双栏右侧 | 滚动此区寻找子功能 | [图 1](./images/focus_01.png) |

小窗或窄屏可只显示一个页面。布局改变后重新定位，同一按钮相对其所属卡片的位置比全屏绝对坐标更可靠。

## 常见控件的识别方法

| 形状 | 一般含义 | 定位时注意 |
|---|---|---|
| 行右端胶囊形轨道＋圆形滑块 | 开关 | 用该行标签确认功能，再读开关状态；灰色不一定表示禁用，也可能只是关闭 |
| 文字行最右端尖括号 | 进入子页 | 当前值／摘要通常在箭头左边，不把摘要当按钮 |
| 圆形单选标记或勾选 | 多选一 | 点目标选项，随后检查选中标记 |
| 水平轨道＋圆形滑块 | 连续或分档数值调整 | 沿真实轨道操作，按标签区分相邻滑块 |
| 横向三点 | 更多菜单 | 先展开菜单，菜单项才可点击 |
| 头像／应用图标＋两行文字 | 对象条目 | 主标题识别对象，第二行可能是状态或数值 |
| 居中白色弹窗＋背景遮罩 | 当前操作需要处理的弹窗 | 优先处理弹窗；按钮按文字识别，不把所有左／右按钮都默认成取消／确认 |

## 操作与结果

| 操作目的 | 如何操作 | 页面变化／结果 |
|---|---|---|
| 操作前确认布局 | 同时检查左侧导航和当前内容标题 | 判断应在导航区还是内容区操作 |
| 找不见条目 | 滚动条目所属区域 | 避免误滚另一个列表 |
| 旋转或调整窗口后继续 | 重新获取截图／控件树并定位目标 | 不沿用改变布局前的坐标 |

## 交互常识与入口缺失检查

部分长文本最多两行后省略，应结合可见前缀、所属分组和当前标题定位。设计中的 dp 间距不作为点击坐标。
