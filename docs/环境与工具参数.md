# 环境搭建与工具全参数

> SKILL.md 的附录。**只在首次搭建环境、或需要查某个参数时读**，日常执行用不到。

## 环境搭建（一次性）

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
adb devices -l                              # 设备在线且已授权
.venv\Scripts\python -m uiautomator2 init   # 设备端初始化（每台设备一次）
```

> ⚠️ **Python 版本**：`rapidocr-onnxruntime` 要求 **Python ≤3.12**（3.13 装不上）。
> 建议用 3.12 建 venv。

## 命令前缀

以下命令省略前缀 `.venv\Scripts\python tools\`。

- 多设备加 `--serial <serial>`；改证据目录加 `--dir`
- `--name` 可省略，缺省自动派生 `<会话id>/step<N>`
- **`--serial/--dir/--name/--full/--no-filter/--settle/--perm-action` 写在子命令前或后都可以**
  （如 `act.py --settle 1500 tap ...` 与 `act.py tap ... --settle 1500` 等价）

## session.py —— 会话生命周期

```powershell
python session.py start --title "日历新建课程表" --input "用户口述的用例原文..."
python session.py finding --status PASS --expect "出现创建成功toast" --actual "OCR读到'创建成功'"
python session.py finish --status PASS --summary "4 步全过，无异常弹窗"
```

| 子命令 | 说明 |
|---|---|
| `start --title --input [--case <id>] [--device] [--package] [--related] [--diag]` | 开会话 |
| `finding --status --expect --actual [--note] [--id]` | 记断言 |
| `finish --status --summary [--package] [--id]` | 收尾写结论 |
| `pause --reason [--ask]` / `resume --id --note` | 遇阻暂停 / 恢复 |
| `perm-intent --action grant\|deny [--perm] [--clear\|--show]` | 声明权限响应意图（**不声明默认 grant**；测拒绝路径时才用） |
| `case add/list/show/update/save` | 用例库维护 |
| `export --id` | 提炼链路卡 |
| `list` / `current` / `abandon` | 查看 / 解绑 |

要点：

- **中文长文本用 `@文件` 传参**（`--input @case.txt`，UTF-8）——命令行直传中文
  在部分终端管道里会被 GBK 双重解码；expect/actual/summary 同理。
- finding 的 expect/actual 必须是**具体判据**（dump 字段值 / OCR 文本），不能只写"正常"。
- **正式用例进用例库**：首次跑通后 `case save --session <N>` 提升；
  复跑 `start --case <id>` 自动带出标题与文本。
- **验证/调试跑动加 `--diag`**：工具自检、探针验证等非正式测试的会话，
  不进「测试记录」库、不计入仪表盘成功率。
- **会话结束后沉淀链路卡**：`export --id <N>` → `knowledge/_runs/<包名>/<id>_<标题>.md`

## act.py —— 动作

```powershell
python act.py tap --x 540 --y 1200 --via rid=com.app:id/btn_ok --why "点击保存" --name c1/s2
python act.py longclick --x 540 --y 1200 --name ...
python act.py input --x 540 --y 1200 --text "你好" --via text="确定" --why "填写标题" --name ...
python act.py input --x 540 --y 1200 --text "追加" --no-click --append --name ...  # 已聚焦不重复点击；追加不覆盖
python act.py swipe --from 540,2000 --to 540,800 --dur 300 --name ...
python act.py back --why "关闭二级页" --name ...      # home / key --code N 同理
```

| 参数 | 说明 |
|---|---|
| `--x/--y` | 坐标，从**本次** nodes 取（禁止复用旧坐标） |
| `--via` | 定位依据（本次坐标从哪个元素推出来），链路卡提炼靠它 |
| `--why` | 这一步的理由（时间轴展示）；back/home/key 也支持 |
| `--settle <ms>` | 稳定窗口，默认 600（写在前后都行） |
| `--perm-action grant\|deny` | 声明权限意图（**测拒绝路径时才需要**；不声明默认同意） |
| `--perm <类型>` | 配合 `--perm-action`，如 `media_images`/`camera` |
| `--watch <specs>` | App 自定义瞬态弹窗，阶段用 `;;` 分隔、阶段内候选用 `\|` |
| `--watch-timeout <ms>` | watch 总窗口，默认 8000 |
| `--full` | nodes 给全量语义节点（默认 nav：只给可点/可滑动节点） |
| `--no-filter` | 不过滤非前台包的节点 |

执行动作 → 稳定窗口 → **自动再做一次 observe**，一个调用回传"动作 + 动作后画面"。

## observe.py —— 看一眼

```powershell
python observe.py --name case172/step01 [--full] [--no-filter]
```

dump UI 树 + 截图 + 前台包名/activity/旋转，一次全给。原始 XML 落盘
`storage/evidence/<name>/dump.xml`。

## read.py —— OCR 读屏

```powershell
python read.py --image storage/evidence/c172/step03/shot.png
python read.py --image <png> --region 100,200,900,400    # x1,y1,x2,y2
python read.py --name case172/step03                     # 不传 --image 则现场截图
```

读 UI 树里没有的东西：toast、Canvas 自绘文字。返回文本 + center 坐标（可直接给 act 用）。
toast 是浮层会消失，act 之后尽快 read。

## state.py —— 设备状态原语

```powershell
python state.py --serial <serial> clear --package com.app
python state.py --serial <serial> grant --package com.app --all-permissions
python state.py grant  --package com.app --perm camera
python state.py revoke --package com.app --perm camera
python state.py start  --package com.app [--activity .MainActivity]
python state.py stop   --package com.app
```

- `--package` 必填。
- `--serial` 指定设备；pm 操作默认针对 Android 用户 0。
- `grant` 的 `--all-permissions` 与 `--perm` 互斥。
- 权限短名：`camera / location / coarse_location / mic / contacts / storage / media_images / notifications`，也接受完整权限名。
- 检查 JSON 的 `ok`；清理结果见 `output`，批量授权另返回 `exit_code`。
- 批量授权的 `ok` 依据命令执行结果；特殊访问权限需另行处理。

何时清理、是否授权，按 [SKILL 权限规则](../SKILL.md#权限准备与执行中的响应)判断。

## logcat.py —— 崩溃取证

```powershell
python logcat.py --serial <s> crash [--package com.app] [--tail 500] [--raw]
python logcat.py --serial <s> clear
python logcat.py --serial <s> setup          # logcat -G 5M（session start 自动做）
```

> `--serial` 与 `logcat.py` 的子命令位置：两种写法现在都支持。

## cleanup.py —— 证据轮转（维护用）

```powershell
python cleanup.py --days 7 [--dry]
```

删除 7 天前的 `evidence/` 与 `logs/`。每步 act/observe 都落全分辨率截图，定期跑。

## webui.py —— Web 测试台

```powershell
python webui.py --port 9810
```

查看会话时间线、截图证据、用例库、知识库、仪表盘。
⚠️ 绑定非回环地址会警告（无鉴权，知识库 POST 可被同网段改写）。
