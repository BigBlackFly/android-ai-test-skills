## 使用时机与入口

仅在用例要求操作桌面现有组件时加载；找不到组件不能用设置页切换代替组件测试。

入口：桌面 > 深浅模式小组件。到达后按下面的可见控件识别，不仅凭页面背景判断。

## 页面识别与布局

桌面 1×1 深浅模式小组件。仅在桌面已存在该组件时可按本页操作。

## 关键控件：形状、位置与操作目标
