# 操作依据不足时的处理

[App 索引](./README.md) · [功能查找](./functions.md)

此文件仅在定位或操作受阻时按需查阅。

| 遇到的情况 | Agent 应如何处理 |
|---|---|
| 一级入口找不到 | 滚动导航列表，尝试搜索；核对地区路径、硬件能力或外设连接，不无限重复 |
| 子项置灰或隐藏 | 检查父开关、权限、外接显示器、阅读省电、全局手写笔等页面注明的依赖 |
| 同一功能有不同布局 | 按屏幕可见的标签和控件选择对应路径，不把多套控件合并操作 |
| 显示大小页两个滑块含义不清 | 用实机标签／控件树区分；无法区分则记录未定位，不猜第二个控件 |
| 屏蔽通知加减号含义不清 | 结合应用所在分组、可访问语义和操作后移动结果判断 |
| 杜比电影滑块标签不同 | 区分媒体音量和人声增强，按实际标签操作 |
| 弹窗未出现 | 不把一次性介绍当作每次必经步骤；确认是否已到达目标页 |
| 跳到账号、安全中心、云服务等其他 App | 确认实际包名和标题，再查目标 App 资料 |
| 缺少下一级流程 | 当前库只提供入口时，不编造内部控件、确认弹窗或结果 |
| 控件定位信息不足 | 结合当前截图与控件树；不凭设计图补造 resource-id、Activity、deeplink 或固定坐标 |

设计图中的应用名、日期、容量、设备标识和开关样例不一定等于当前数据。文中明确的默认值是设计依据，不能代替操作前读取当前状态。本包未经过实机验证。

需要确认图标或标注时再打开页面局部图；需追溯原件时查看 [sources.md](./sources.md)。来源文件名不决定页面归属。

## 资料不足时的最小记录

记录目标功能、测试要求的入口、当前App及页面、已检查区域、关键前置状态、相关截图和尚未确认的问题。区分以下情况：

| 结论类别 | 含义 |
|---|---|
| 未找到入口 | 当前定位未成功，不代表产品不具备该功能 |
| 条件不满足 | 已观察到本页注明的父项／设备等限制；是否调整由用例决定 |
| 资料未覆盖 | 已到达库中未描述的页面或缺少控件语义，需结合实机继续识别或补充资料 |
| 设计与实机差异 | 当前界面与图稿不一致，记录实际证据；测试结果仍按用例预期判定 |

入口位置、控件说明、交互结果来自原设计资料；新增的检索同义词、排查顺序、返回核对和加载顺序是面向Agent的执行建议。建议不能被当作产品功能事实。
